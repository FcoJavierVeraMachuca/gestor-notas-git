# Gestor de Notas Git

## Descripción
Este proyecto es una aplicación para gestionar notas personales utilizando control de versiones. 

## Funcionalidades
* Crear, editar y borrar notas. 
* Almacenamiento de versiones con Git

## Cómo ejecutar el programa
1. Clonar el repositorio
2. Ejecutar el archivo principal desde el terminal o IDE
